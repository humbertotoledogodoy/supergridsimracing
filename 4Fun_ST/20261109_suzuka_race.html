Como ler os dados

A posição final usa a ordem oficial de resultado do server (essa é sempre exata, inclusive para quem foi cortado pelo tempo). A posição por volta usa a posição registrada no resultado do server quando disponível; caso contrário, é calculada comparando todos os pilotos no mesmo instante de tempo de sessão (tempo acumulado desde a largada), e não pelo total final de voltas de cada um. Essa estimativa é precisa para quem completou a distância total da corrida. Para pilotos cortados pelo tempo (menos voltas que o líder), a ordem entre eles pode ficar imprecisa perto do fim da corrida, pois o server não registra o avanço parcial na volta incompleta em que a corrida terminou para esses pilotos.
